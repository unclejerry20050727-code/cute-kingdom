# 可愛國 🏝️

一個可以直接在瀏覽器開啟的 2D 等距小島生活遊戲——**無建置、無依賴、無 CDN**，純 HTML / CSS / Canvas / JS。

## 快速開始

- 直接用瀏覽器打開 `index.html`（雙擊即可），或
- 本機 server：`python3 -m http.server 8080` → <http://localhost:8080>
- 存檔自動存在瀏覽器 localStorage（key：`cute-kingdom-save-v1`），重開瀏覽器會問你要不要繼續

## 玩法

1. **建立角色**：男／女預設或自訂（髮型、髮色、膚色、服裝）
2. **片頭教學**：醒來 → 遇見小夥伴 → 放第一張床（床是教學錨點，之後不可移除）
3. **出門**：小島地圖四處走 → 麥當勞商店買制服／帽子 → 選關卡打工（五關由易到難：排隊 1→5 人、耐心 20→8s、工資 1→2 倍；看訂單→組餐點→收錢，有連擊小費與下工星星評價，見「麥當勞打工」章節）
4. **回家裝修**：點「建造」開啟建造面板（見下）

**操作**：WASD／方向鍵或點地板移動、對話用按鈕／空白鍵推進、放置家具時 **R 旋轉 90°**（床/書桌/沙發/鋼琴等非正方形品項）、**↑↓／W S／滾輪調牆飾高度**（已掛好的牆飾點一下→移動 ghost→再點確認）、**Esc** 取消放置或關面板、觸控裝置可用左下 **🔄▲▼✖️** 按鈕（等同 R／↑↓／Esc）、**歲數氣球**放置中或調整中按 **R／🔄 換數字 1-9**、房間自由狀態或地圖場景按 **P／📷 擺拍**（10 姿勢輪流，1.8 秒自動恢復，移動鍵取消）、按 **C／📸 拍照**（下載目前場景 PNG）、右上角喇叭鈕靜音（會記住）。

|---|---|---|
| 家具 | 床(1) 書桌(2) 椅子(4) 沙發(2) 書架(3) 五斗櫃(2) 落地燈(3) 鋼琴(1) | 佔格、會擋路；床不可移除 |
| 擺飾 | 盆栽(3) 花瓶(3) 泰迪熊(2) 氣球(2) | 不擋路可走過；**可放家具上**（自動站在家具頂面） |
| 地飾 | 地毯(2) 門墊(1) 地板貼(4) 小花叢(3) | 平鋪層在地面上；同層不可重疊、可與家具同格 |
| 牆飾 | 心形框(2) 星星框(2) 時鐘(1) 海報(2) 牆架(2) 彩旗(1，跨 2 槽) | 按牆面槽位掛；窗戶／門上方的槽不可用；**高度可調**（已掛的點一下再調）；**上下錯開可同槽多掛**（垂直範圍重疊會被拒） |
| 節慶 🎉 | 地：生日蛋糕(1) 禮物盒(3) 聖誕樹(1) 南瓜(2) 紅燈籠(2) 爆竹(2) 氣球束(2)；牆：春聯(2) 福字(1) 冬青花環(2) 彩燈串(1，跨 2 槽) 蜘蛛網(2) 歲數氣球(1) | 地飾平鋪地面（規則同地飾層）；生日蛋糕／禮物盒**可放家具上**；牆飾按槽位掛（高度可調、上下錯開可同槽多掛）；**歲數氣球數字 1-9** 放置中或調整中按 R／🔄 換 |
| 裝潢 | 牆面色 5 色、地板色 5 色 | 自由混搭，隨存檔保存 |
| 移除 | — | 點「移除」後點家具／擺飾／牆飾即可取下；同格多件時**先標最上面的**（擺飾在家具上→先拆擺飾再拆家具） |

- 本版本所有品項**免費**（金錢與計價為佔位，不影響放置）
- 放置會即時存檔；重載後家具、牆飾、換色全部保留
- **旋轉**：放置中按 R 可把非正方形品項（床/書桌/沙發/鋼琴 2×1）旋轉 90°（變 1×2），足跡判定、擋路格、移除標記、存檔全部跟隨旋轉
- **擺飾上家具**：擺飾（盆栽/花瓶/泰迪熊/氣球）可放在家具同一格，高度即時計算——家具移除擺飾落地、後放家具擺飾站上去；同類擺飾之間不可重疊
- **牆飾高度**：放置中用 ↑↓／W S／滾輪調高度（6px 步進、限定範圍 50~262px）；已掛好的牆飾在自由狀態點一下→進調整模式（實物隱藏、ghost 跟隨新高度）→再點確認寫入存檔（Esc 取消）
- **觸控按鈕**：放置中左下角顯示 🔄▲▼✖️ 一列（🔄 僅非正方形家具、▲▼ 僅牆飾、✖️ 常駐），等同 R／↑↓／Esc（真實觸控事件已驗證）
- **節慶裝飾（第十四輪）**：🎉 分頁共 7 地飾（生日蛋糕/禮物盒/聖誕樹/南瓜/紅燈籠/爆竹/氣球束，涵蓋春節/聖誕/萬聖/生日）＋6 牆飾（春聯/福字/冬青花環/彩燈串/蜘蛛網/歲數氣球）；生日蛋糕與禮物盒可放家具上（自動站在家具頂面）；彩燈串照彩旗慣例跨 2 槽；歲數氣球的數字（1-9）在放置或調整時按 R／🔄 循環，數字寫入存檔（reload 保留）；牆飾分頁只列原 6 件牆飾不重複
- **擺拍＋拍照（第十五輪）**：房間自由狀態或地圖場景（第十六輪）按 **P** 或 📷 鈕循環 10 姿勢（✌️比耶/👋揮手/🙌歡呼/💃跳舞/💕張開雙臂/🙏比心合掌/🫡敬禮/💪秀肌肉/🧘打坐/😉啾咪），角色轉正面、頭頂漂浮表情、1.8 秒自動恢復（按移動鍵立即取消）、建造面板開啟時禁用；按 **C** 或 📸 鈕把畫面 `toDataURL` 下載為 `cute-kingdom-<時間戳>.png`（全程序化繪製無跨域污染）；姿勢不存檔（瞬間動作）
- **第十六輪**：① 地圖場景也支援擺拍＋拍照（同一套 10 姿勢、1.8 秒恢復、地圖移動取消）；② 牆飾同槽可多件——只要上下錯開（每件品項有 `sizeH`，垂直範圍重疊＋2px 縫才拒絕；放置/滾輪/▲▼/wallAdj 全路徑即時重驗）；③ 封面換正式海報 `art/game-cover.png`
- **移除優先序**：移除模式 hover 到多件重疊的格位時，永遠先標最上面那件——站在家具上的擺飾先拆、再拆下面的家具（床仍受保護不可移除）

## 麥當勞打工（第十三輪）

- **關卡**：商店裡 5 張關卡卡（新人上工／熟手班／忙碌時段／午休尖峰／全店總動員），先買齊制服＋帽子才能打工；**前一關拿 ★1 才能解鎖下一關**，最佳星數存檔
- **難度**：越後面排隊人數越多（1→5，後面的人越遠越小，排隊中的人頭上有小訂單圖示）、耐心越短（20s→8s）、工資倍率越高（1.0→2.0x）
- **訂單**：5 種食材（麵包胚/肉片/番茄/生菜/起司）×5 品項（經典漢堡/起司吐司/蔬菜堡/雙層堡/特製套餐），每品項各有食譜與價格；照氣泡食譜由下到上點卡
- **尖峰客⚡**（L4+ 25%、L5 35% 概率）：耐心×0.6、工資×1.5，要快點處理
- **耐心條**（服務中客人頭上，綠→橘→紅）：歸零就 💢 氣走（算 miss、報廢已疊的料），下一位上前並自動補新客
- **連擊**：連續完成不點錯，左上顯示 🔥 連擊 xN；**每 3 連 +10 小費**（點錯或客氣走會中斷）
- **下工結算**：星星評價（每關不同完成數門檻，如 L1 做滿 4/8/12 個得 1/2/3 星）＋新紀錄標示，★1 起解鎖下一關
- 60 秒一班；點右上 ✕ 可提前下班（不算成績）

## 手機操作（第十四輪）

- 直式手機完整遊玩已驗證（390×844、iPhone 14 viewport、真實觸控非模擬）：建角 → 教學 → 放床（手指拖曳 ghost）→ 出門 → 地圖走路 → 商店買制服＋帽子 → 打工 L1（完整訂單→上菜→快轉結算）→ 回家建造（牆飾拖曳/調高/移除）→ 重新整理續玩
- canvas 觸控與滑鼠輸入統一：tap＝click、拖曳＝只移 ghost 不誤放；`touch-action: none` 防頁面捲動縮放
- 觸控按鈕 🔄▲▼✖️ 用真實觸控事件（驗證非模擬點擊）；手機端建造面板全寬、建角預覽框放大 484px、對話框收小；打工場景手機略小為日後 polish 項
- 測試：`node test/peek-mobile.mjs`（21 步 40 項斷言、0 pageerror）

## 音訊

- BGM 用**純 `<audio>`** 播放（`file://` 與 `http://` 都有效）；Web Audio 只負責 SFX（合成音效）
- `mp3-test.html` 是音訊實驗頁：`file://` 下第 2/3 層（MediaElementSource 路徑）預設靜音，屬設計內行為
- BGM 素材與授權：`music/CREDITS.txt`

## 專案結構

```
index.html          單頁入口
css/style.css       全部樣式
js/util.js          通用工具（存檔、音效 hook、canvas 輔助）
js/character.js     角色造型（髮型/髮色/服裝）與繪製
js/world.js         世界幾何（等距投影）、房間/地圖繪製、BUILD_ITEMS 目錄
js/audio.js         BGM（<audio>）＋ SFX（Web Audio 合成）
js/game.js          遊戲狀態機、輸入、建造面板、對話
art/                角色立繪素材
music/              BGM mp3
test/               Playwright 測試腳本（見下）
shots/              回歸截圖（測試產物，隨 commit 更新）
PROGRESS.md         逐輪開發紀錄
```
